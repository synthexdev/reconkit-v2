# ReconKit

ReconKit es una herramienta de reconocimiento desarrollada en Python como proyecto de aprendizaje.

Actualmente incluye diferentes funciones relacionadas con reconocimiento de red, información del sistema y generación de reportes.

## Características

* Escaneo de puertos
* Ping
* Resolución DNS
* Información del sistema
* Generación de reportes
* Interfaz para utilizar las diferentes funciones

## Requisitos

* Python 3
* Las dependencias indicadas en `requirements.txt`

## Instalación

Cloná el repositorio:

```bash
git clone https://github.com/TU-USUARIO/ReconKit.git
cd reconkit-v2
```

Instalá las dependencias:

```bash
pip install -r requirements.txt
```

## Uso

Ejecutá el archivo principal:

```bash
python3 reconkit.py
```
